## 🌟 게임 소개 (Overview — 한국어 & English)

**ARGONIA: Crown of the Spire (아르고니아: 첨탑의 왕관)**는 최근 글로벌 인디 게임계를 휩쓴 바이럴 히트작들(**Thronefall**의 직관적인 주야간 왕국 건설·수성, **Vampire Survivors**의 군주 직접 전투와 광역 스킬 쾌감, **Balatro / Slay the Spire**의 유물·세트 시너지 덱빌딩)의 핵심 재미를 결합해 **Three.js 3D WebGL**과 **100% 절차적 WebAudio 오케스트라 신디사이저**로 구현한 풀스케일 전략 액션 로그라이트 웹게임입니다.

- **☀️ 낮(Day — 정비 및 경제 부흥)**: 황금빛 햇살 아래 금광, 풍차 농장, 아르곤 결정 정제소를 세워 왕국 경제를 부흥시키고, 길목에 성벽과 방어 포탑·병영을 증축합니다. 파괴된 모든 성벽과 건물은 여명이 밝을 때 100% 자동 재건됩니다.
- **🌙 밤(Night — 군주 직접 전투 & 대규모 공성 방어)**: 종을 울려 밤을 맞이하면 하늘이 심연의 밤하늘로 전환되고 차원문에서 수백 기의 적군과 거대 액트 보스가 진격합니다. 플레이어는 직접 **수호 군주(Monarch Hero)**를 조작해 스킬(`Q`, `E`, `R`, `Space`)을 퍼붓고 병영의 성기사·발키리 군단을 집결(`T`)시켜 최전선을 사수합니다.
- **📜 여명(Dawn — 왕실 칙령 & 유물 시너지 드래프트)**: 매 밤을 생존할 때마다 48종의 왕실 유물 중 하나를 하사받아 **6대 성좌 시너지 세트(2/4/6세트 효과)**를 완성하고, 획득한 **별빛 왕관(👑)**으로 **왕실 성소(24종 영구 특성)**를 해금합니다.

### 3. 🏰 10종 건물 × 3단계 증축 + 20종 분기형 궁극 진화 (Dual Tier-3 Specializations)

모든 건물은 **Lv.1 → Lv.2 → Lv.3** 강화 후, 플레이어의 전략에 따라 **2가지 궁극 특화 진화(Tier-3 Evolution)** 중 하나로 분기합니다.

- **🏰 왕실 성채 (Citadel Keep)** → `☀️ 태양왕의 황금 옥좌` *(전체 포탑 공격력 +20%, 여명 골드 대폭 증가)* vs `🌌 성좌의 불멸 요새` *(성채 체력 7,200, 모든 건물 초당 자동 재생)*
- **⛏️ 왕실 금광 (Gold Mine)** → `⚙️ 지각 관통 메가드릴` *(아르곤 동시 채굴 & 주변 지진 피해)* vs `🏦 연금술 황금 조폐국` *(보유 금화 12% 이자 지급 & 처치 골드 +25%)*
- **🌾 풍차 농장 (Windmill Farm)** → `🛡️ 민병대 무장 곡창` *(병사 체력 +42% & 자체 창병 파병)* vs `🍺 풍요의 축제 양조장` *(영웅·병사 공격/이동 속도 +22%)*
- **💎 아르곤 정제소 (Argon Refinery)** → `⚡ 과충전 아르곤 축전탑` *(주변 포탑 공속 +30% 오라)* vs `🔮 성좌 공명 수확기` *(영웅 스킬 쿨타임 20% 단축)*
- **🏹 궁수 감시탑 (Archer Watchtower)** → `🎯 거신병 파괴 발리스타` *(초장거리 관통 & 보스 피해 +65%)* vs `🌪️ 폭풍연사 개틀링 석궁` *(초당 5회 2연발 폭풍 사격)*
- **🔮 비전 오벨리스크 (Arcane Obelisk)** → `🔦 공허 분해 레이저 프리즘` *(방어 무시 피해 증폭 레이저)* vs `⚡ 천둥폭풍 테슬라 코일` *(최대 8기 동시 연쇄 뇌전 & 기절)*
- **💣 화염 박격포 (Flame Mortar)** → `🌋 아마겟돈 네이팜 다연장포` *(반경 6.2m 초광역 용암 장판)* vs `🐉 홍련의 용숨결 화염방사탑` *(초고속 연사 & 적 장갑 25% 융해)*
- **❄️ 빙결 첨탑 (Frost Spire)** → `🌨️ 절대영도 눈보라 방출기` *(72% 둔화 & 35% 확률 완전 빙결)* vs `💎 빙결정 파쇄 공명탑` *(피해 +35% 증폭 & 처치 시 얼음 파편 폭발)*
- **⚔️ 왕실 병영 (Royal Barracks)** → `🛡️ 불멸의 황금 성기사단` *(광역 망치 강타 & 자가 치유 탱커)* vs `🪽 천공의 발키리 창기병대` *(초고속 기동 & 공중 적 요격 가능)*
- **🧱 요새 성벽 (Bastion Stone Wall)** → `🩸 피의 가시 반사 성루` *(근접 피해 60% 반사 & 가시 충격파)* vs `🛡️ 아르곤 룬 역장 성문` *(초당 45 재생 & 주변 아군 방어 버프)*

## 🎮 조작 방법 및 단축키 (Controls & Shortcuts)

| 입력 / 단축키 | 동작 설명 |
| :--- | :--- |
| **`W` `A` `S` `D` / 방향키** | 수호 군주(영웅) 이동 (카메라 회전 방향 기준 자동 보정) |
| **마우스 좌클릭** | 건설 부지(Socket) 선택 또는 해당 지점으로 군주 이동 |
| **마우스 우클릭 + 드래그** | 3D 전장 카메라 360° 회전 (클릭 시 이동 명령) |
| **마우스 휠 스크롤** | 3D 디오라마 카메라 줌 인 / 줌 아웃 |
| **`Q` / `E` / `R`** | 군주 고유 액티브 스킬 1 / 2 / 궁극기 발동 |
| **`Space`** | 전술 돌격 대시 (경로상 적에게 충격파 피해) |
| **`T`** | **전군 집결 (Rally)** — 모든 아군 병영 부대를 영웅 위치로 소집 |
| **`B`** | **스마트 자동 건설/강화** — 보유 자원으로 최적의 부지를 즉시 건설·강화 |
| **`F`** | 현재 선택된 부지 즉시 건설 / 다음 단계 강화 |
| **`Enter`** | **전투 개시 (밤 맞이하기)** — 정비 종료 후 야간 웨이브 시작 |
| **`V`** | 카메라 시점 전환 (`전술 디오라마` ↔ `3인칭 액션캠` ↔ `전체 조망`) |
| **`M`** | 절차적 WebAudio 오케스트라 사운드 음소거 토글 |
| **`P`** | 4K 왕국 연대기 포스터 PNG 즉시 저장 |
| **`H`** | Zen 시네마틱 모드 (HUD 숨기기/표시) |
| **`ESC`** | 왕실 사령부 (왕국/영웅 변경, 성소 특성, 도감, 업적) 열기/닫기 |

## 🛠️ 로컬 실행 및 테스트 (Local Development)

```bash
git clone https://github.com/jeiel85/argonia.git
cd argonia

# 의존성 설치 (Three.js & Vite)
npm install

# 개발 서버 실행 (http://localhost:5179)
npm run dev

# 유닛 및 헤드리스 시뮬레이션 테스트 실행
npm test

# 5대 왕국 캠페인 AI 밸런스 시뮬레이터 실행
npm run simulate

# 프로덕션 빌드
npm run build
```
